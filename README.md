# oTTeVerse

oTTeVerse will and is building a modern Rust blockchain for games and metaverse economies.

This repository publishes the definition of what we are building:

- Site: the first-person definition, white background, mark top-left
- PDF: [`public/otteverse-definition.pdf`](public/otteverse-definition.pdf) (same document)

```bash
npm install
npm run dev
```

Regenerate the PDF:

```bash
python scripts/generate_pdf.py
```
